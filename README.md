# Mis apps: Hábitos y Foco

Apps que funcionan sin conexión, se instalan en el celular (iPhone y Android) y en la PC, y se sincronizan entre dispositivos.

## 1. Subir a GitHub (una sola vez)

1. Entrá a https://github.com y creá una cuenta si no tenés.
2. Arriba a la derecha: **+ → New repository**.
3. Nombre: `mis-apps`. Marcá **Public**. Tocá **Create repository**.
4. En la página que aparece, tocá **uploading an existing file**.
5. Arrastrá **todo el contenido** de esta carpeta (los archivos .html, .json, sw.js y la carpeta `icons`). Tocá **Commit changes**.

## 2. Publicarla como página web

1. En el repositorio: **Settings → Pages**.
2. En *Branch* elegí `main` y la carpeta `/ (root)`. Tocá **Save**.
3. Esperá 1 o 2 minutos. Tu dirección va a ser:
   `https://TU-USUARIO.github.io/mis-apps/`

## 3. Instalar en el teléfono

- **iPhone (Safari):** abrí la dirección → elegí la app → Compartir → **Agregar a pantalla de inicio**.
- **Android (Chrome):** abrí la dirección → elegí la app → menú ⋮ → **Instalar app**.
- **PC (Chrome o Edge):** abrí la dirección → ícono de instalar en la barra de direcciones.

Después de abrirlas una vez, funcionan sin internet.

## 4. Sincronizar PC y teléfono

1. En la PC, abrí la app → botón **Sincronizar dispositivos** → **Crear sincronización nueva**. Seguí la guía para crear la base gratuita de Firebase (5 minutos, una sola vez).
2. Copiá el **código SYNC-…** que aparece.
3. En el teléfono, abrí la misma app → **Sincronizar dispositivos** → **Ya tengo un código** → pegá el código.
4. Repetí para la otra app (Hábitos y Foco tienen cada una su código).

Desde ahí, lo que cambies en un dispositivo aparece en el otro.

## Actualizar

Cuando recibas archivos nuevos, subilos al mismo repositorio (**Add file → Upload files**) reemplazando los anteriores. Las apps instaladas se actualizan al abrirlas con conexión.
